# req-change 输出示例（参考材料）

> 本文件是 `commands/req-change.md` 的配套示例，按需 Read，不随命令加载。

## 小调整（默认自动分类）

```bash
/crs:req-change FEAT-20260514-001-a3b2c1 --reason "按钮文案从'提交'改为'保存'"
```

```markdown
📝 需求变更 - FEAT-20260514-001-a3b2c1
🔍 变更分类: 小调整
✅ 变更完成，继续执行
```

## 中等变更（--impact）

```bash
/crs:req-change FEAT-20260514-001-a3b2c1 --reason "增加密码强度验证" --impact
```

```markdown
📝 需求变更 - FEAT-20260514-001-a3b2c1

🔍 变更分类: 中等变更

⚠️ 影响评估:
影响任务: 2个
- FEAT-20260514-001-a3b2c1-T03: 前端表单验证
- FEAT-20260514-001-a3b2c1-T05: 后端验证逻辑
预估耗时: 30分钟

建议: 更新任务 T03 和 T05

✅ 已调整执行计划
📝 已记录变更历史
```
